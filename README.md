# Análisis de números en un array (Java)

## Descripción
Este programa en Java analiza un conjunto de números almacenados en un array para:
- Encontrar el **valor mayor**.
- Contar **cuántas veces se repite** dicho valor dentro del array.

## Funcionamiento del programa
1. Se declara un array de números enteros.
2. Se toma el primer elemento como valor máximo inicial.
3. Se recorre el array para encontrar el número mayor.
4. Se vuelve a recorrer el array para contar cuántas veces aparece ese número.
5. Se muestra por pantalla el valor mayor y su número de repeticiones.
